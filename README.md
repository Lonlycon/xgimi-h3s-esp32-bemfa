# 极米 H3S 智能遥控（ESP32 + 巴法云 + 网页）

用一块 ESP32 接管极米 H3S 投影仪的日常操作：

- **开机**：模拟原装蓝牙遥控器发广播包
- **关机**：向投影发 UDP 快速关机指令
- **按键**：冒充极米 App，走 TCP 13145 的 JSON 协议（方向/确定/返回/菜单/音量）
- **语音**：通过巴法云接入小爱，说"打开/关闭投影仪"
- **网页**：手机浏览器直接遥控，不占巴法云主题
- **电脑显示模式**：一句话/一下点，让电脑切扩展/复制/仅投影/仅电脑

当前版本 **v2.0**。v1.0 只做了"开关机 + 小爱"，已用 git tag `v1.0` 固定，未被覆盖。

## 2. 架构

```
                        手机小爱 / 米家场景
                                │
                       巴法云 MQTT（bemfa.com:9501）
                                │
                    ┌───────────▼────────────┐
                    │         ESP32          │
   手机浏览器 ──HTTP──▶ WebServer :80         │
                    │                        │
                    │  ① 蓝牙广播 31 字节 ────┼──▶ 投影开机
                    │  ② UDP 16750 ──────────┼──▶ 投影关机
                    │  ③ TCP 13145 ──────────┼──▶ 投影按键/查询
                    │  ④ TCP 8080 探测 ──────┼──▶ 判断开关状态
                    └───────────┬────────────┘
                                │ UDP 54321
                                ▼
                    电脑 display_switch.py（托盘）
                                │
                                ▼
                    DisplaySwitch.exe 切换显示模式
```

### 三条控制通道的区别

| 通道 | 协议 | 用途 | 备注 |
|---|---|---|---|
| 蓝牙广播 | BLE 31 字节 | **只用于开机** | 关机后投影断网，只能用蓝牙唤醒 |
| UDP 16750 | JSON | **关机** | 已验证，保留 |
| **TCP 13145** | JSON（8 字节帧头） | **按键、查询** | 新增，官方 App 正在用 |

> v1.0 用的是 UDP 16735 的 `KEYPRESSES:xx` 文本协议，那是**老版 App** 的接口，
> H3S 当前固件根本不认。v2.0 已废弃，改为 TCP 13145。

## 3. 硬件

| 件 | 说明 |
|---|---|
| ESP32 开发板 | 实测 ESP32-D0WD-V3（CH340 串口） |
| 5V 电源 | **必须独立常电**，不要插投影 USB（投影关机后 ESP32 也断电，就无法唤醒） |

接线：只给 ESP32 插 USB 供电即可。板载 LED（GPIO2）作状态灯：
常亮 = 已开机，快闪 = 开机中，慢闪 = 未开机。

## 5. 配置

复制 `secrets.example.h` 为 `secrets.h`，填入：

```cpp
#define WIFI_SSID       "YOUR_WIFI_SSID"
#define WIFI_PASS       "YOUR_WIFI_PASSWORD"
#define PROJECTOR_IP    "192.168.0.30"      // 投影 IP
#define BLE_TOKEN_HEX   "YOUR_32_HEX_TOKEN" // 32 个十六进制字符
#define BEMFA_UID       "YOUR_BEMFA_KEY"
#define BEMFA_TOPIC     "touying001"

#define PC_IP           "192.168.0.10"      // 运行 display_switch.py 的电脑
#define PC_PORT         54321
```

`secrets.h` 已在 `.gitignore` 中，不会提交。

> `PC_IP` 也可以不写：固件有默认值，而且**能在网页上改**，会存进 flash。

## 6. 编译与烧录

```powershell
$cli = "tools\arduino-cli\arduino-cli.exe"
$fqbn = "esp32:esp32:esp32:PartitionScheme=huge_app"

# 编译
& $cli compile --fqbn $fqbn .

# 烧录（COM4 换成实际端口）
& $cli upload -p COM4 --fqbn $fqbn --upload-property upload.speed=460800 .
```

| 参数 | 值 | 原因 |
|---|---|---|
| 分区 | `huge_app` | 固件 ~1.7MB，默认 1.3MB 装不下 |
| 上传速度 | `460800` | 921600 在 CH340 板子上到 96% 会掉线 |
| 串口监视 | 115200 | |

正常启动日志：

```text
=== XGIMI H3S v2.0 (ESP32 + bemfa + web) ===
[CFG] PC IP = 192.168.0.10 (来自 secrets.h)
[BLE] mem_release=ESP_OK
[BLE] controller_init=ESP_OK
[WiFi] ok, ip=192.168.0.21
[MQTT] connecting ... ok
[MQTT] sub touying001   OK
[MQTT] sub kuozhan001   OK
[WEB] 打开 http://192.168.0.21/ 即可遥控
[init] state=1
```

`state` 含义：0 未知 / 1 已关机 / 2 开机中 / 3 已开机 / 4 关机中。

## 7. 网页遥控

手机连同一个 Wi-Fi，浏览器打开 **`http://<ESP32的IP>/`**。

- 状态栏每 3 秒刷新：投影状态、MQTT/蓝牙/电脑连接、实时 IP
- 按钮均为固定尺寸，不随窗口缩放
- 页面结构：电源 / 方向·确认（含返回、菜单）/ 音量 / 电脑显示模式 /
  试码 / 复杂指令 / 设置电脑地址

### 按键码（全部实测）

| code | 按键 | code | 按键 |
|---|---|---|---|
| 1 | 左 | 6 | 返回 |
| 2 | 右 | 9 | 音量 + |
| 3 | 上 | 10 | 音量 − |
| 4 | 下 | 12 | 菜单 |
| 5 | 确定 | | |

> **对焦 / 信号源没有码值**：`code` 扫过 0–50 没有对应功能，
> 推测不在按键通道里。可用"试码"继续找，找到后可加按钮。

### 网页接口

| 接口 | 作用 |
|---|---|
| `GET /` | 遥控页面 |
| `GET /api/status` | 状态 JSON |
| `GET /api/cmd?n=menu` | 按名字发按键 |
| `GET /api/key?c=12` | 按码值发按键（试码用） |
| `GET /api/power?on=1` / `?on=0` / `?toggle=1` | 开机 / 关机 / 电源键 |
| `GET /api/disp?m=0..3` | 切电脑显示模式 |
| `GET /api/cc?m=7&t=3` | 发 UDP 复杂指令（调试用） |
| `GET /api/setpc?ip=x.x.x.x` | 改电脑 IP（存 flash） |

## 8. 电脑显示模式

### 8.1 原理

```
网页按钮 / 米家 → ESP32 → UDP 54321 → display_switch.py → DisplaySwitch.exe
```

为什么绕经 ESP32？因为巴法云**一个私钥同时只能有一个 MQTT 连接**，
电脑若也去连会把 ESP32 顶下线。让 ESP32 做中间人最稳。

### 8.2 部署

1. 把 `tools/display_switch.py` 和 `tools/start_display_switch.bat` 拷到电脑同一目录
2. 装依赖：`python -m pip install pystray pillow`
3. 开防火墙（**管理员**）：

   ```powershell
   netsh advfirewall firewall add rule name="XGIMI Display UDP" dir=in action=allow protocol=UDP localport=54321
   ```

4. 双击 `start_display_switch.bat`（用 `pythonw` 启动，无黑框）

### 8.3 托盘图标

| 颜色 | 含义 |
|---|---|
| 🟢 | 正常监听 |
| ⚪ | 已暂停 |
| 🔴 | 出错（如端口被占用） |

右键菜单：状态 / 已接收次数 / 最近一条 / 暂停恢复 / 打开日志 / 退出。
双击图标 = 打开日志。日志超过 1MB 自动轮转。

> 开机自启用**任务计划程序**，触发器"登录时"，务必勾选**"只在用户登录时运行"**。
> 勾错会跑在服务会话里，`DisplaySwitch` 切的是看不见的桌面。

## 9. 小爱 / 米家

### 9.1 巴法云主题

| 主题 | 含义 |
|---|---|
| `touying001` | 投影开关 |
| `kuozhan001` | 扩展 |
| `fuzhi001` | 复制 |
| `jinzhu001` | 仅投影 |
| `jinpc001` | 仅电脑 |

命名规则：**前缀随意，后三位数字是设备类型**，`001` = 插座。

### 9.2 米家

米家 → 我的 → 其他平台设备 → 添加 → 巴法 → 同步设备。
再建"手动场景"，动作选"打开 kuozhan"等，可添加到桌面。

> 米家通常**不显示第三方设备卡片**，属正常限制；小爱语音可用。

### 9.3 按键"复位"机制

米家场景动作是"打开插座"，第二次点会因状态没变而不下发。
所以固件收到显示模式指令后**立刻 publish "off"** 复位，让它永远是个可反复按的按钮。

## 10. TCP 13145 协议（v2 核心发现）

### 10.1 帧格式

```
┌──────────────┬────────────────┬──────────────┐
│ FF FF E0 4A  │  4 字节大端长度 │  UTF-8 JSON  │
└──────────────┴────────────────┴──────────────┘
```

### 10.2 交互流程

```
10000 握手   →  10001（设备信息）
10003 注册   →  10004
50022 查能力 →  50022
50036 按键   →  50036（回声）
20000 系统   →  20001 / 30236 / 30412 / 100000（未知命令）
```

### 10.3 报文示例

按键（菜单）：

```json
{"action":50036,"commonCmd":{"action":"3","code":"12","type":"inst"}}
```

系统指令（关机）：

```json
{"action":20000,"controlCmd":{"delayTime":0,"mode":6,"time":0,"type":0},"msgid":"2"}
```

### 10.4 `controlCmd.mode` 已知取值

| mode | 作用 |
|---|---|
| 6 | 快速关机 |
| 7 | 获取应用列表 |

> 其余 mode 未逐一验证。`type` 似乎表示指令类别（0 = 电源/系统，3 = 应用）。

## 12. 常见问题

| 现象 | 排查 |
|---|---|
| MQTT `rc=-2` | Wi-Fi 没连上 / DNS 失败，检查 2.4GHz |
| MQTT `rc=5` | 巴法私钥不对 |
| 巴法某主题一直离线 | 主题是在设备上线**之后**才建的 → 固件每 60 秒自动重订阅，等一分钟即可 |
| 网页按键没反应 | 投影必须开机且 13145 可达；看网页顶部"投影"状态 |
| 首次按键慢半拍 | 要建 TCP + 握手，之后复用连接，约 100ms |
| 电脑显示模式没反应 | 防火墙 54321 未放行 / `PC_IP` 不对 / 托盘图标是红色 |
| 有日志但屏幕不切 | 别在远程桌面里测；确认 `DisplaySwitch.exe /extend` 手动可用 |
| 上传到 96% 掉线 | 上传速度改 460800 |

## 13. 已知限制

- **对焦 / 信号源**：未找到协议指令；`code` 0–50 均无对应功能。
- 米家不显示第三方平台设备卡片，属平台限制。
- 巴法云一个私钥同时只能有一个连接，所以电脑端必须经 ESP32 中转。
- 小爱 → 巴法 → ESP32 有 1–3 秒云端延迟。
- 网页无鉴权，同一局域网内任何人可打开（家用可接受）。
- 固件依赖厂商私有协议，**投影系统升级后可能失效**（已有 H3 用户升级后 UDP 指令失效的先例）。
  升级前请记录系统版本（本机为 `GMUI 5.1.100.02` / `v3.19.288`）并备份本项目。
- 仅供自用，不要商品化；不要对接/仿冒小米云协议。
